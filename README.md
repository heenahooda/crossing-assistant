# Crossing Assistant, version WITHOUT the ML model (for the `crossing-assistant` repo)

Same app as crossing-assistant-ml (redesign + 30 s / 60 s "can't see the road" rule + danger alerts +
emergency contact). Detection is simulated with the demo buttons; no .tflite file is needed or used.

Upload ALL files in this folder (not the folder itself) to the `crossing-assistant` repo, replacing the old ones:
index.html, warm.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable-512.png
Then Settings -> Pages (already set) -> wait about 1 minute -> close and reopen the installed app.
